# CORES ($CORES)

100 reactor cores. One pool. Fees only.

**Live site:** https://useliving.github.io/cores/  
**X:** https://x.com/UseCores

## How it works
The pool's liquidity is cut into 100 price bands, and each band belongs to one core (an NFT). Whichever core the price is sitting in goes critical: every swap there pays it the fee. Nothing else ever pays a core.

## What's on the site
- A live pixel-art reactor hall of all 100 cores; hover and click any core
- Floor map with filters, liquidity bar, pool stats and a core inspector (8-byte spec, fee, earnings)
- Live pulses and surges logs
- Play wallet to mint, buy and list cores in the simulation
- Readme, FAQ and $CORES token panel

Single self-contained `index.html`.

> Pre-launch: prices, swaps, surges, mints and wallets on the site are a simulation. Memecoins and NFTs are extremely risky. Not financial advice.
